# Notes MVP и проекты

Noma хранит заметки локально в IndexedDB через Dexie. Проект — это универсальная `Note` с `isProject: true`; вложенность хранится через `parentId`.

Реализовано: маршруты проектов, breadcrumbs, создание дочерних заметок и проектов, прямые ссылки на заметки, перемещение в корень или другой проект, защита от циклов, архивирование/корзина/восстановление subtree, soft delete и окончательное удаление.
# Time Tracking (MVP 0.4)

У любой заметки или проекта можно включить учёт времени. Сессии сохраняются в IndexedDB, поддерживают Start/Pause/Resume/Stop, ручные замеры, итоги и историю. Одновременно работает только один таймер.

Цель сохраняет целевые часы и фиксированный локальный календарный дедлайн. Норма пересчитывается по оставшимся часам и календарным дням. В компактном интерфейсе блок цели показывает цель, дедлайн и остаток, а блок таймера — общее время, время сегодня и нужное количество часов в день. График, опережение/отставание и прогноз намеренно не входят в MVP 0.5.

## История версий заметок (MVP 0.7)

Noma хранит persistent snapshots перед значимым изменением Note или Project: title, content, color, Today/Inbox, расположение в дереве, учёт времени, настройку Pomodoro и поля цели. Повторные autosave объединяются в окно редактирования три минуты; для одной Note остаются последние 100 версий. В History можно посмотреть старую версию, восстановить всю Note или вернуть только title и content. Version Restore сохраняет тот же id и tracking sessions; если старый parent больше недоступен или создаёт цикл, остаётся текущий безопасный parent. Restore из Trash/Archive — отдельное lifecycle-восстановление, а не откат версии.

## Резервная копия рабочего пространства (MVP 0.8)

Локальное рабочее пространство можно экспортировать и восстановить как versioned JSON: заметки, tracking sessions, revisions и tombstones, а также workspace/device identity. Планируемое место на Drive — видимая пользовательская папка `Google Drive / Noma/`; `appDataFolder` не используется. Загрузка в Drive недоступна до настройки OAuth credentials.

## Локальный desktop-режим

Команда `npm run desktop` собирает существующий frontend, запускает Node-сервер только на `127.0.0.1:3847` (или следующем свободном порту) и открывает обычный браузер. `npm run desktop:serve` запускает сервер без открытия браузера. Это не cloud backend и не нативный EXE.

Для portable-папки Windows выполните `npm run build:windows`. В игнорируемой Git папке `release/Noma-portable/` будут `Noma.exe`, встроенный runtime, `Noma.cmd`, `Noma.ps1`, `README_RUN.txt`, production `dist/` и локальный сервер. Node.js на целевом компьютере не требуется.

## Noma 1.0 Beta

`npm run build:windows` создаёт `release/Noma-portable/Noma.exe` и добавляет рядом встроенный Node runtime. Дважды кликните `Noma.exe`, чтобы запустить Noma офлайн без установки Node.js. Переносить нужно всю portable-папку. Подписи и Windows-инсталлятора пока нет.

## MVP 0.9 — portable, 0.9.0-local.0

Сборка: `npm run build:portable`. Переносите всю папку `release/Noma-portable` с Noma.cmd, Noma.ps1, README_RUN.txt, dist и server. Требуется Node.js 22.12+ или 24 LTS в PATH; установка npm-зависимостей на целевом компьютере не нужна. Это подготовка к EXE, без встроенного Node и подписи.

Запуск: Noma.cmd. Браузер открывается автоматически, сервер слушает только 127.0.0.1:3847. Занятый порт заменяется следующим; NOMA_PORT задаёт начальный порт. Остановка: Ctrl+C в терминале. Закрытие браузера не останавливает сервер. Noma.ps1 зависит от политики PowerShell. Перед пересборкой остановите сервер.

Данные хранятся в IndexedDB браузера, а не в portable-папке. Другой порт или профиль может выглядеть пустым: вернитесь к исходному порту/профилю или используйте экспорт/импорт рабочего пространства. Перед переносом компьютера экспортируйте данные. Проверки: lint, typecheck, test, build, build:portable.


## 2026-09-08

Заметки сохраняются автоматически при изменениях, в том числе до закрытия редактора. Внизу — «Закрыть», сверху — кнопка закрепления. Перетаскивайте карточки внутри закреплённой или обычной группы. В плане на сегодня по умолчанию есть закреплённые «Текущие дела» и «Постоянные дела». Цель можно сохранить без даты. Сворачивание таймера ставит его на паузу; сброс сохраняет учтённое время в истории. Создание проекта находится в боковом меню. Логика ядра отделена от переменных темы; план будущих плагинов и тем — в ../EXTENSIBILITY.md.


## Уточнение таймера — 08.09.2026

Маленький кружок заполнен зелёным при запущенном и приостановленном таймере. Сворачивание ставит таймер на паузу. «Сбросить общее время» находится под «Всего» и обнуляет только общий счётчик: история, прогресс цели и «Сделано сегодня» сохраняются. «Сбросить таймер» перенесено в меню с точками рядом с отдельным «Сбросить Pomodoro».


## Рисование — 08.09.2026

Внизу редактора — иконка пера в круге. Она открывает холст с карандашом, пером, маркером, ластиком, выбором цвета и толщины, отменой и повтором. Ластик удаляет целый штрих; действие можно отменить. Рисунок сохраняется автоматически, отображается в заметке и карточке, включается в историю версий и резервную копию. Нажмите галочку, чтобы вернуться к заметке.
